# Prototype 5
1. What went well?
2. The player movement worked well, and I was able to add jumping and double jumping. I also added wall running and wall jumping to make the movement feel more like Titanfall 2.
3. What didn’t go well?
4. I learned the difference between taking inspiration from a game and directly copying it.
5. What challenges did you face? (Technical, creative, or production)
6. The biggest challenge was understanding how the original game's movement worked and figuring out how to recreate the basic idea without directly copying the original game. 
7. What can you do differently next time?
8. Next time, I would study the original mechanic more carefully before starting. I would identify which parts I want to use as inspiration and then design my own version instead of trying to copy everything.
